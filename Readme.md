# AtCoder

競技プログラミングで利用する C++ のアルゴリズム・データ構造ライブラリです。
`AtCoder/` ディレクトリには、グラフ、数論、文字列、DP、幾何、データ構造などの実装を用途別のヘッダとして収録しています。

## 構成

- `AtCoder/header.h`: 型エイリアス、入出力設定、ループマクロなどの共通定義
- `AtCoder/*.h`: 分野ごとのアルゴリズム・データ構造
- `AtCoder/main.cpp`: 実装を試すためのエントリーポイント
- `AtCoder.sln`: Visual Studio 用ソリューション

## 使い方

1. `AtCoder/header.h` と使用したいヘッダを解答ファイルと同じディレクトリに配置します。
2. 解答ファイルから必要なヘッダをインクルードします。

```cpp
#include "header.h"
#include "DP.h"

int main() {
    // 問題の解法を記述する
}
```

ヘッダ間には依存関係があるため、個別のヘッダを利用する際は、そのヘッダがインクルードしているファイルも併せて配置してください。

## 開発環境

Visual Studio のソリューションでは C++20 を使用しています。GNU C++ などの提出環境では、必要なヘッダを単一ファイルに展開して提出することを想定しています。

AtCoder Library を利用する機能は、提出環境で `<atcoder/all>` を利用できる場合に有効になります。
